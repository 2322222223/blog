Docker 系统梳理

1. 什么是 Docker？

Docker 是一个开源的平台，用于开发、交付和运行应用程序。通过将应用程序及其依赖项打包到称为容器的标准化单元中，Docker 使应用程序更易于构建、移植和运行。

2. Docker 体系结构

Docker 的体系结构由以下主要组件组成：

  • Docker 客户端：用户与 Docker 交互的主要方式，通过命令行（CLI）发出指令。
  • Docker 守护进程（Daemon）：负责构建、运行和管理容器的后台服务。它监听来自 Docker 客户端的 API 请求。
  • Docker 镜像：只读模板，包含运行容器所需的所有内容（代码、库、环境变量等）。
  • Docker 容器：由镜像实例化而来的可运行单元。每个容器都是一个独立的进程。
  • Docker 注册表：用于存储和分发 Docker 镜像的仓库。Docker Hub 是最常用的公共注册表。

3. Docker 工作流程

  • 构建（Build）：通过 Dockerfile 定义镜像并构建。
  • 发布（Ship）：将构建的镜像推送到 Docker 注册表。
  • 运行（Run）：从镜像创建并启动容器。
