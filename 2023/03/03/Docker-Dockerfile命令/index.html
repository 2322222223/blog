完整的 Dockerfile 编写指南

Dockerfile 是用于创建 Docker 镜像的文本文件，它包含了一系列指令，Docker 使用这些指令自动构建镜像。本文将介绍 Dockerfile 的基本结构、常用指令、优化技巧，以及不同编写方式的对比分析。

1. Dockerfile 基本结构

一个典型的 Dockerfile 包含以下基本部分：

  • 基础镜像：使用 FROM 指令指定。
  • 维护者信息：使用 LABEL 指令（之前使用 MAINTAINER）。
  • 工作目录：使用 WORKDIR 指令指定。
  • 复制文件：使用 COPY 或 ADD 指令。
  • 运行命令：使用 RUN 指令。
  • 暴露端口：使用 EXPOSE 指令。
  • 默认命令：使用 CMD 或 ENTRYPOINT 指令。

2. 常用 Dockerfile 指令

FROM

指定基础镜像。每个 Dockerfile 必须以 FROM 开头。

LABEL

添加元数据（如维护者信息）。

WORKDIR

设置工作目录。

COPY 和 ADD

复制文件到镜像中。ADD 可以解压 tar 文件并从 URL 复制文件。

RUN

在镜像构建时运行命令。

EXPOSE

暴露端口。

CMD 和 ENTRYPOINT

设置容器启动时运行的命令。CMD 可以被 docker run 的命令行参数覆盖，而 ENTRYPOINT 不会。
